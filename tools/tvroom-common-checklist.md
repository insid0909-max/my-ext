# 티비룸 1.0.9 공통 기능 보완

사용자 요청 범위는 공통 기능만입니다. 재생 메서드·키 처리·클라이언트·프록시·영상 헤더와 화질 경로는 변경하지 않습니다. 순정 앱 재생 전환이나 CLAUDE.md 전체 준수를 의미하지 않습니다.

주소 확인과 자동 찾기 설정, 페이지 통신 재시도, 한글 주소/리다이렉트 보존, 검색 보완, 필요한 회차 번호 보정, 영화 본편 이름, 실제 날짜/상태, 표지 회귀 방지, 목록 캐시와 대기 제한, 탭 규칙과 수정 이력 유지를 적용합니다. 사이트에 없는 정보를 만들지 않습니다.

검사: 원본 재생 메서드 문자열 일치·한글 주소 처리 보존·Node 구문 검사·모의 표지/주소/날짜/검색/회차/영화 검사. 실제 사이트 및 Glitch 실기기 재생은 미확인입니다.

## 1.0.10 타이머 호환성 수정

clearTimeout을 사용하지 않습니다. setTimeout도 없으면 통신 자체 timeout을 사용하고 페이지 간 인위적 대기를 생략합니다. 취소 함수 없음·Promise형 타이머·타이머 모두 없음 환경에서 검사 13개를 통과했습니다. 원본 재생·키·프록시 등 다른 코드는 변경하지 않습니다. 실기기 검증은 별도입니다.

## 1.0.11 방영 상태와 회차 표시

영화는 완결을 유지합니다. 그 외에는 최근 회차의 한국 날짜 기준 21일 이내를 방영 중, 22일부터 완결로 추정합니다. 날짜가 없거나 미래 날짜뿐이면 기존 명시 상태를 유지합니다. 일반 회차는 10회 (11.08) 형식으로 표시하며 날짜가 없으면 번호와 단위를 표시합니다. 특집·예고·부 구분, 중복 보정 번호, scanlator, 회차 URL과 날짜는 보존합니다. 이름 변경은 기존 다운로드 표시를 바꿀 수 있습니다. 재생·키·프록시는 변경하지 않습니다. 경계/예외/상세 모의 검사와 구문 검사이며 실기기 확인은 별도입니다.
